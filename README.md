# Find the Way! — Our Town, Cupang!

18 direction activities for children, with a single correct path per activity.
All graphics, styles, and game code are included in index.html.

## GitHub Pages
1. Create a new public repository, for example cupang-direction-game.
2. Upload index.html to the repository root and commit to main.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the URL displayed by GitHub Pages after deployment completes.

Upload the extracted index.html, not the ZIP file or its enclosing folder.
Use a separate repository to preserve your existing matching game.

## Classroom
Use Chrome in landscape orientation. Tap Play to begin.
Help starts OFF. Tap Help to highlight the next correct direction.
Sound controls both sound effects and English destination narration.
English narration uses the browser/device speech service; voice availability varies by device.
No login, image uploads, package installation, or build step is required by this game.
